# GiftGenie Simple

This is a simplified version of GiftGenie that generates Amazon search links with your Associate Tag and does not require API keys.

## Setup

1. Replace `PARTNER_TAG` in `app.py` with your actual Amazon Associate Tag (e.g., `giftgenie0d-21`).
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run the app:
   ```
   streamlit run app.py
   ```
4. Open your browser to `http://localhost:8501` to use the app.
